## Overview

A fully functional back-end API for an e-commerce platform, built to mirror the architecture used by platforms like Shopify and WooCommerce. The project was scoped using a formal **user story** before any code was written — a PM practice that keeps development anchored to real user needs.

[View on GitHub →](https://github.com/VithusanU/E-commerce-BackEnd)

## User Story

> **AS A** manager at an internet retail company
> **I WANT** a back end for my e-commerce website that uses the latest technologies
> **SO THAT** my company can compete with other e-commerce companies

Starting with a user story before writing a single line of code reflects a PM-first mindset. It forces clarity on *who* the system serves and *why* it exists — before jumping to *how* it's built.

## Features

- **Full CRUD Operations** — Create, read, update, and delete for Products, Categories, and Tags
- **Relational Data Modelling** — Products belong to Categories; Products have many Tags through a join table
- **RESTful Endpoints** — Clean, predictable API structure following REST conventions
- **ORM with Sequelize** — Abstracts raw SQL into readable, maintainable model definitions
- **Data Seeding** — Pre-populated test data for immediate development and testing

## Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **ORM:** Sequelize
- **Database:** MySQL
