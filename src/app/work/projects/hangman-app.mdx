## Overview

A fully featured browser-based Hangman game with a polished night sky visual theme, category-based word selection, real-time letter feedback, sound effects, and a lives system.

[Live App →](https://vithusanu.github.io/Hangman-App/) &nbsp;|&nbsp; [View on GitHub →](https://github.com/VithusanU/Hangman-App)

## Features

- **Category-Based Words** — Words drawn from Animals, Foods, Sports, Games, and Companies
- **7-Life System** — Progressive visual hangman drawing with each incorrect guess
- **Color-Coded Feedback** — Green for correct letters, red for wrong guesses
- **Dictionary Hints** — Each word comes with a definition clue to help players reason through it
- **Sound Effects** — Audio feedback enhances the game feel on correct and incorrect guesses
- **Score Tracking** — Live score displayed throughout gameplay
- **Play Again** — Instant restart for new rounds without a page reload

## Tech Stack

- **JavaScript** — Core game logic, state management, and DOM manipulation
- **CSS** — Animated night sky background, responsive card layout
- **HTML** — Semantic page structure

## Design Thinking

The night sky aesthetic wasn't an accident — it sets a calm, focused mood that's distinct from typical game UIs. The decision to include dictionary-style hints adds an educational layer, making the game feel more thoughtful than a standard word guesser.

The color-coded letter keyboard (green = correct, red = wrong) is a deliberate UX choice: it gives players a persistent visual map of their guesses without requiring them to remember what they've tried.
